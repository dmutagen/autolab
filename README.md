## 🚀 Основные возможности

* 📐 **Строгий Белорусский ГОСТ (СТБ 2154 / ГОСТ 7.32)**:
  * Поля страницы: левое — 30 мм, правое — 10 мм, верхнее — 20 мм, нижнее — 20 мм.
  * Шрифт текста: **Times New Roman 14 pt**, абзацный отступ (красная строка) ровно **1.25 см**, выравнивание по ширине.
  * Межстрочный интервал: строго **одинарный (1.0)**, отступы до и после абзаца — **0 pt**.
  * Обычное начертание (без лишнего жирного шрифта в тексте заголовков и шапки).
  * Шрифт программного кода: **Times New Roman 11 pt**.
  * Подписи к иллюстрациям: **14 pt**, среднее тире (en-dash `–`), по центру без точки на конце (`Рисунок 1 – Результат выполнения программы`).
* 🔄 **Каскад моделей Gemini (Google AI)**:
  * Автоматический каскадный переход при исчерпании лимитов (`429`) или перегрузке (`503`):  
    `gemini-2.5-flash` ➔ `gemini-3.7-flash` ➔ `gemini-3.5-flash` ➔ `gemini-3.8-flash` ➔ `gemini-3.6-flash`.
  * Быстрый отклик генерации (от 1.5–3 секунд на задачу).
* 📱 **Умные скриншоты интерфейса программы**:
  * **Мобильные приложения (Android)**: автоматическая генерация реалистичного макета экрана смартфона (статус-бар, кнопки, Toast-уведомления, навигационная панель).
  * **Консольные / Алгоритмические задачи (Python, Java, C++, SQL, Bash)**: компиляция и запуск в изолированной песочнице, создание эстетичного снимка окна терминала с реальным выводом.
  * **Собственные скриншоты**: поддержка загрузки пользователем реального скриншота через форму.
* 📄 **Короткие имена файлов по стандартам колледжа**:
  * `МОБ_35.docx`, `разраб2.docx`, `СУБД_1.docx`, `ТРПО_5.docx`, `ИБ_1.docx`, `схема10.docx`.
  * Возможность задать своё собственное имя файла прямо в веб-интерфейсе.
* ⚙️ **Гибкость настроек**:
  * Выбор даты работы (вручную или текущая).
  * Опциональный блок теории (по умолчанию выключен — сразу идёт практическая часть).
  * Опция титульного листа для практик и курсовых отчетов.
  * Если вариант не указан — строка «Вариант» не добавляется.

## 💻 Установка и запуск

### 🔑 Получение бесплатного API-ключа Gemini
1. Перейдите в [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Нажмите **Create API key** (создать ключ).
3. Скопируйте ключ вида `AIzaSy...` или `AQ.Ab8...`.

---

### 🐧 Linux (Ubuntu / Debian / Arch / Fedora)

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/dmutagen/autolab.git
   cd autolab
   ```

2. **Установите Python 3.10+ и компиляторы (если ещё не установлены):**
   * *Ubuntu / Debian:*
     ```bash
     sudo apt update && sudo apt install -y python3 python3-venv python3-pip git default-jdk g++
     ```
   * *Arch Linux:*
     ```bash
     sudo pacman -S python python-pip git jdk-openjdk gcc
     ```

3. **Запустите систему (скрипт сам создаст виртуальное окружение и установит зависимости):**
   ```bash
   chmod +x run.sh
   ./run.sh
   ```
4. Откройте в браузере: **http://127.0.0.1:8000**

---

### 🪟 Windows 10 / 11

1. **Установите Python:**
   * Скачайте Python 3.11 или 3.12 с официального сайта [python.org](https://www.python.org/downloads/).
   * ⚠️ **Важно:** при установке обязательно поставьте галочку **"Add Python to PATH"**.

2. **Клонируйте или скачайте репозиторий:**
   ```powershell
   git clone https://github.com/dmutagen/autolab.git
   cd autolab
   ```
   *(или скачайте ZIP-архив с GitHub и распакуйте в удобную папку)*.

3. **Создайте виртуальное окружение и установите библиотеки в PowerShell / CMD:**
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\activate
   pip install -r requirements.txt
   ```

4. **Запустите сервер:**
   ```powershell
   python -m uvicorn server:app --host 127.0.0.1 --port 8000
   ```
5. Откройте в браузере: **http://127.0.0.1:8000**

---

### 🍎 macOS

1. **Установите Homebrew (если нет) и Python:**
   ```bash
   brew install python git
   ```

2. **Клонируйте репозиторий и запустите:**
   ```bash
   git clone https://github.com/dmutagen/autolab.git
   cd autolab
   chmod +x run.sh
   ./run.sh
   ```
3. Откройте в браузере: **http://127.0.0.1:8000**

## 🖥 Использование

### 1. Веб-интерфейс
* Откройте `http://127.0.0.1:8000`
* Нажмите кнопку **⚙️ Настройки** в шапке и введите свой Gemini API ключ и ФИО / группу.
* Заполните форму:
  * **Предмет**: выберите кнопкой (*Мобилки*, *Разработка ПО*, *СУБД*, *ИБ*, *ТРПО*, *Схемотехника*) или введите вручную.
  * **Вариант**: укажите номер (например `18`), либо оставьте пустым (строка варианта в отчёте создаваться не будет).
  * **Дата**: по умолчанию сегодняшняя, можно изменить.
  * **Имя файла**: можно оставить автогенерацию или написать своё (например `МОБ_35`).
  * **Файл**: перетащите методичку в формате `.pdf`, `.docx` или фото/скриншот программы.
  * **Текст задания**: вставьте задание или вопросы из методички.
* Нажмите **«Сгенерировать работу по ГОСТу»**.
* Через несколько секунд нажмите **«Скачать .DOCX»**.

### 2. Консольный режим (CLI)
Систему можно запускать прямо из терминала без браузера:

```bash
# Генерация с коротким именем и датой
./run.sh --subject "Разработка приложений для мобильных устройств" \
         --variant 18 \
         --date "24.03.2026" \
         --task "Анимации картинок Translate, Rotate, Scale"

# Интерактивный пошаговый мастер
./run.sh -i

# Генерация по файлу методички
./run.sh --file /path/to/metodichka.pdf --variant 5
```

## 📁 Структура проекта

```text
autolab-ai/
├── autolab/
│   ├── config.py         # Настройки ГОСТа, профиль студента, каскад моделей
│   ├── docx_builder.py   # Генератор DOCX строго по ГОСТ Беларуси
│   ├── executor.py       # Песочница компиляции/запуска кода (Java, Python, C++, SQL, Bash)
│   ├── gemini_client.py  # Клиент Google Gemini с каскадным переключением
│   ├── knowledge.py      # База академических стандартов и промптов
│   ├── parser.py         # Парсер методичек (PDF, DOCX, изображения)
│   ├── pipeline.py       # Главный конвейер сборки работы
│   └── screenshot.py     # Рендерер смарт-скриншотов (Android UI / Terminal)
├── static/               # Современный темный веб-интерфейс
│   ├── app.js
│   ├── index.html
│   └── style.css
├── config.example.json   # Пример конфигурации
├── requirements.txt      # Зависимости Python
├── run.sh                # Автозапуск на Linux / macOS
├── server.py             # FastAPI сервер
└── README.md
```
